Dashboard built for Power BI Service (web version only).
Visualizes Wisconsin county-level data for a general public audience.
Core lens across every page: female vs. male comparison.

Client: Wisconsin Women's Council

DEMOGRAPHICS

// DATA TABLES

fact2_acs_wi_county
  Rows: ~62,424 (+ 11,808 C24010 rows added 2026-07-05)
  Columns: geoid, county, year, var_base, estimate
  Note: Sentinel value -666,666,667 used by ACS for suppressed
        medians — filter estimate > 0 in all earnings measures

dim_demographic
  Rows: 867
  Columns: var_base, topic, sex, race, age_group, marital_status,
           education_level, is_denominator, description
  Notes:
    - B20017 sex encoded in var_base (_003=male, _006=female)
      sex column = "Total" — fixed in build_dims.py
    - B22002 householder sex fixed in build_dims.py
    - Topic names normalized:
        "Education Level" → "Demographics / Education Level"
        "Marital Status"  → "Demographics / Marital Status"
        "Sex by Work Experience..." → "Earnings / Work Experience"

dim_occupation
  Rows: 288 (S2411/S2412) + 154 (C24010 added 2026-07-05)
  Columns: var_base, table, worker_type, sex, row_number,
           occupation_label, occupation_level, is_median_earnings_row
  C24010 additional columns: occupation_nesting, race
  Notes:
    - S2411 = all civilian workers
    - S2412 = full-time year-round workers
    - C24010 = occupation worker counts by sex and race
    - occupation_nesting: "top" (5 major categories),
      "branch"/"leaf" (not yet pulled)

dim_geography
  Rows: 72 (one per Wisconsin county)
  Columns: geoid, county, county_name, state

fact_wish_births_county — FUTURE
fact_crime_agg — FUTURE


// ============================================================
// RELATIONSHIPS (Power BI Model)
// ============================================================

fact2_acs_wi_county[geoid]    → dim_geography[geoid]       M:1  Active
fact2_acs_wi_county[var_base] → dim_demographic[var_base]  M:1  Active
dim_occupation[var_base]      → dim_demographic[var_base]  1:1  Active
fact2_acs_wi_county[var_base] → dim_occupation[var_base]   M:1  INACTIVE
  ↑ Inactive to avoid ambiguous path error. Activated via
    USERELATIONSHIP() in C24010 measures only.


// ============================================================
// KEY DAX PATTERNS
// ============================================================

Statewide KPI (ignore county slicer):
  CALCULATE([Measure], ALL(dim_geography))

Sentinel value filter (earnings medians):
  AVERAGEX(FILTER(fact2_acs_wi_county, fact2_acs_wi_county[estimate] > 0), ...)

C24010 occupation counts (inactive relationship):
  CALCULATE(..., USERELATIONSHIP(fact2_acs_wi_county[var_base], dim_occupation[var_base]), ...)

Dynamic page title:
  [Selected County] = IF(HASONEVALUE(dim_geography[county_name]),
                         VALUES(dim_geography[county_name]),
                         "All Wisconsin Counties")
